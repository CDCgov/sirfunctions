# Create the country-prioritization code template

Create the country-prioritization code template

## Usage

``` r
generate_country_prioritization_template(output_path, name, edav)
```

## Arguments

- output_path:

  Parent output folder.

- name:

  Run-folder name.

- edav:

  Whether the run uses EDAV.

## Value

No return value. Writes an R script to the run folder.
