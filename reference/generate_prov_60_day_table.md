# PROV 60-day follow-up table

PROV 60-day follow-up table

## Usage

``` r
generate_prov_60_day_table(cases.need60day, prov_name)
```

## Arguments

- cases.need60day:

  Output from
  [`generate_60_day_table_data()`](https://cdcgov.github.io/sirfunctions/reference/generate_60_day_table_data.md).

- prov_name:

  PROV name.

## Value

A flextable.
